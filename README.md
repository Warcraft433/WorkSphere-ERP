# WorkSphere ERP

🚀 A production-style ERP system built while learning the Java Full Stack ecosystem.

This project is being developed step by step, starting with **Core Java** and gradually evolving into a **Spring Boot + React** enterprise application. Every new concept learned is directly implemented into this project.

* 🔨 **Phase 1: Core Java — In Progress**

* ✅ OOP-based design

## Project Status

⚠️ **This project is actively under development.**

The current milestone is a functional **Core Java Employee Management System** with CRUD operations, array-based storage, and an interactive console menu.

The frontend will be developed in parallel while the backend continues through Collections, Exception Handling, Java 8, JDBC, and eventually Spring Boot.
